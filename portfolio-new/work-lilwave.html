自创 IP 品牌视觉体系，从角色造型、世界观设定到 IP 周边开发，构建完整的原创 IP 视觉系统。获上实城开（0363.HK）一年独家授权，雕塑装置落地进行中。

一个始于个人练习的虚构品牌项目，却意外迎来了现实的浪花，这是一只"反英雄"式的海鸥。它调皮搞怪，虽然喜欢冲浪却并不擅长，但它拥有无所畏惧的精神。它闲暇时最爱吃薯条和可乐。通过塑造一个"不完美但勇敢"的形象，我们希望传递，即使不擅长，也要勇敢去尝试。

No Wave, No Surf — 无浪不冲。
勇敢去冲，不要错过每一个浪。

已授权上实城开（股票代码：0363.HK）非独家部分商业使用 · 雕塑装置落地进行中
Gallery · 视觉呈现

与品牌设计师 weason 合作孵化冲浪文化品牌 Hi WAVE。我热爱海洋，潜水，而海鸥形象则源于彼时流行的"去码头整点薯条"网络梗图，两种渴望碰撞融合：一边是冲向大海的自由，一边是整点薯条的日常幽默。该项目最初旨在探索"品牌人格化"的可能性。

令人惊喜的是，项目发布后获得上实城开 [股票代码：0363.HK] 关注，目前已签署授权协议，计划将 IP 形象转化为公共艺术雕塑装置，落地于上海临港新区 103 地块项目中。
