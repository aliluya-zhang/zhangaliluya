01 / 问题分析

核心问题诊断

在原产品模具不变的前提下，完成一次从视觉到触觉的品牌重塑。在「专业科技」与「女性温和」之间找到平衡，建立一套有辨识度、可执行、可感知的品牌视觉体系。

整体视觉定位

视觉体系混乱，偏男性化，缺乏统一性与品牌识别度。

产品配色重塑

配色偏男性化，无法传递温和与柔肤感。

Logo 标识重塑

现无形或缺乏专业与温和的平衡感。

包装配件重塑

包装风格不统一，材质与结构缺乏品牌感。

02 / 产品配色重塑

Color System

专业而不冰冷，科技而有温度。暗调玫瑰金成为主色，裸粉与香槟金作为辅色与点缀，构建有层次的「暖调科技感」。

Primary
暗调玫瑰金
Secondary

Accent

Before / After

原配色以黑银为主，工具感强。新配色以暗调玫瑰金 70%、裸粉色 20%、香槟金 10% 重新分配，柔化科技感知，增强女性亲和力。

05 / 虚拟模特

Via

Via 是 NenoVia 的品牌虚拟形象，以统一的视觉语言贯穿所有传播触点。她不是超模，也不是网红，而是一位 28 岁、住在哥本哈根的护肤品配方师。雀斑、浅金短发、温和自然的穿搭，让她看起来既真实又亲近。

06 / IG 社媒设计

Social Presence

账号整体运营调性统一：Ins 主页、短视频、海报、互动标准一致。以 Via 为核心，围绕护肤场景输出系列内容，建立真实、可信赖的品牌人格。

07 / 独立站设计

Website Design

建立品牌数字化门面，从首页到产品详情页，统一视觉语言与交互体验。通过大图展示、清晰的信息架构、以及品牌色的贯穿应用，让用户在浏览过程中感受到 NenoVia 的专业与温度。

网站设计以暗调玫瑰金为主色，搭配大量留白与精致的产品摄影，营造出高端护肤品牌的质感。响应式设计确保在移动端同样拥有出色的浏览体验。
