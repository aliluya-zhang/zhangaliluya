Design Strategy
整体视觉定位 视觉体系混乱，偏男性化，缺乏统一性与品牌识别度。 确立「暖调科技感」为核心视觉语言：在专业护肤科技框架中融入柔和温暖的气质，避免冷硬或过度女性化。
产品配色重塑 配色偏男性化（如深蓝、黑、灰），无法传递温和与柔肤感。 主色：裸粉色、淡玫瑰金。辅色：暖灰、深灰。点缀色：柔光珊瑚橙或香槟金，用于科技感细节。
Logo 标识重塑 现无形或缺乏专业与温和的平衡感。 采用圆角无衬线字体，字形略带弧度。图标结合抽象「N」+「水润结合」
包装配件重塑 包装风格不统一，材质与结构缺乏品牌感。 统一盒型结构
Logo Redesign

Logo 标识重塑

以字母"N"为基础，通过斜向线条与渐变疏密，塑造"由表及里"的渗透感，精准对应产品打开肌肤通道、促进精华吸收的核心功能。

Logo uses diagonal lines and a gradient from dense to sparse to create a sense of "surface-to-deep" penetration. It directly echoes the product's core function — opening up skin channels and boosting serum absorption.

Product Color Redesign

产品颜色重塑

主色采用哑光玫瑰金，配合底部细磨砂外壳，让金属不再冰冷，而是沉稳、有触感。
引入裸粉色作为辅助点缀，柔化产品与环境的对比，整体视觉从"实验室工具"转向"浴室里的安静伴侣"。

品牌虚拟模特

via

通过品牌虚拟模特统一视觉输出，建立与用户的长期情感连接。

Via 是 NenoVia 的品牌虚拟形象，以统一的视觉语言贯穿所有传播触点。她不是超模，也不是网红，而是一位 28 岁、住在哥本哈根的护肤品配方师。雀斑、浅金短发、温和自然的穿搭，让她看起来既真实又亲近。通过 Via 的品牌声线与视觉输出，我们与用户建立长期的情感连接——不是冷冰冰的代言，而是像朋友一样陪伴每一次护肤仪式。
